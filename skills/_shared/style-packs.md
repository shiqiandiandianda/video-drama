# 风格锁词包（唯一出处）

> `ProjectManifest.visual_style_lock` 的配套词包，全集群唯一出处；其他文件只引用不复制。
> 用途：S04 图 Prompt 与 S05 段 body 必须镜像本项目风格锁的正词包；负词包并入负面约束。
> 旧项目续跑缺 `visual_style_lock` → HUMAN_GATE 补锁，不得默认猜测。

## 1. 枚举

```yaml
visual_style_lock: GUOMAN_3D_CG | LIVE_ACTION_REALISM   # ProjectManifest 必填
```

## 2. LIVE_ACTION_REALISM（真人写实）

正词包（必须镜像）：

```text
真人实拍短剧风格，真实演员、真实皮肤纹理、真实服装与真实场景材质。
电影级实拍质感，24fps，180°快门，自然电影运动模糊。
自然肤色、真实光影、实拍景深、真实物理重量与接触反馈。
```

负词包（并入负面约束）：

```text
禁止 3D 渲染感、CG 感、动画感、卡通感、二次元、建模脸、塑料皮肤、
磨皮过度、游戏贴图质感、虚拟棚拍感、数字替身感。
```

## 3. GUOMAN_3D_CG（3D 国漫）

正词包（必须镜像）：

```text
3D 国漫 CG 风格，高精度角色建模，细腻材质渲染，风格化光影。
统一角色脸型与五官比例，统一发色发型与服装设计，电影级 CG 运镜质感。
```

负词包（并入负面约束）：

```text
禁止真人照片感、实拍质感、真实皮肤毛孔、纪实风格、
画风突变、2D 平涂感、日漫画风、美漫画风、低多边形感。
```

## 4. 互斥规则

- 两词包互斥：渲染时只镜像 Manifest 指定的一款，禁止混用对方词包的任何词汇。
- 词包冲突即不合格：body/Prompt 中出现对方风格锁词汇 = 硬检不通过。
- 画幅、机型、帧率等摄影基准不属于词包，由 `_shared/segment-format.md` 第三节与机型规则包给出。
