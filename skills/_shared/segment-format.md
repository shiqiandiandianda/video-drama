# 段级视频提示词格式图纸（canonical）

> 本文件是十五节段级视频提示词格式的**唯一出处**，由 `docs/reference-final-prompt-参考素材说明.txt` 收编而来。
> 派生关系：S05 契约的结构化字段 schema 以 §2 为准；`render_segment_prompt.ps1` 的渲染模板以 §3 为准；S06 `qa-video-prompt.md` 的 conformance 检查以 §4 为准。
> 纪律：任何生产 skill 的输入不得包含本文件原文作为填空模板；LLM 只产结构化字段，body 由渲染脚本机械拼装。格式调整只改本文件，三处派生同步更新。

## 1. 总则

- 一个段 = 一条视频 Prompt = 15 秒（seedance-2.0）或 30 秒（seedance-2.5），段内含 2–6 个连续镜头，单镜 ≥1.5 秒，各镜时长之和 = 段时长。
- 段内镜头之间是"切镜"（下一镜直接继承镜尾状态，禁止重置）；段间是"承接"（上段终帧 → 本段 0.0 秒直接继承）。
- 结构化字段是事实主源；十五节 `body` 是渲染产物。二者冲突即不合格；body 中任何事实无法指回结构化字段即不合格。
- 任一字段无上游出处 → 阻断，禁止编造。
- 核心生成优先级（高→低）：剧情因果 > 人物位置与前中后景空间 > 动作连续 > 表演与对白节奏 > 运镜与构图 > 摄影参数与质感。摄影参数不得凌驾于剧情与动作。
- 每一条信息必须至少回答：谁在哪里 / 谁实焦谁虚焦 / 摄影机在哪里朝哪里 / 人物在做什么为什么 / 摄影机何时移动 / 焦点落在哪 / 何时说话怎么说 / 关键词配什么动作 / 镜头结束在哪 / 下一镜如何承接 / 下一段如何继续。回答不了任何一条的文字删除。

## 2. 十五节字段 schema

每节给出：槽位 → 结构化字段（类型）→ 唯一事实主源。`→静态` 表示该节文案固定，仅做槽位替换。

### 一、参考素材说明
| 槽位 | 字段 | 主源 |
|---|---|---|
| 角色/场景/道具/音频/分镜图槽位 | `reference_bindings[]`（object_ref, mixed_slot 正整数，usage_scope） | 项目资产台账 + S05 槽位编号 |

- `mixed_slot` 从 1 连续自增无空号；不同对象不得共槽，同一对象不得重复分配；正文槽位集合与 `reference_bindings` 完全一致。
- 分镜图/站位图槽位仅 VISUAL_TRACK 存在。

### 二、参考素材使用规则 →静态
按素材类型固定文案（角色只参考脸部/年龄感/肤色/发型发色/身材/服装/伤势；场景只参考建筑结构/空间关系/材质/环境/门窗家具/固定视觉特征；道具只参考尺寸/材质/颜色/形状/结构/正确使用方式；分镜图只参考站位/景别/构图/镜头方向/运镜逻辑，不继承草图风格/文字/编号/箭头/边框/标签）。末尾固定："本段未出现的人物、场景、道具不得自行增加。"

### 三、统一视觉与摄影基准
| 槽位 | 字段 | 主源 |
|---|---|---|
| 画幅/机型/帧率/快门 | `task.aspect_ratio`、机型规则包（24fps、180°快门） | Manifest + `_shared` 机型规则 |
| 本场风格 | `scene_tone.style` | S02 |
| 整体色彩 | `scene_tone.color_palette` | S02 |
| 整体节奏 | `scene_tone.rhythm` | S02 |
| 风格正/负词 | 风格词包镜像 | `_shared/style-packs.md` |

固定约束渲染：摄影机运动只在人物动作、视线变化、信息揭示或情绪爆点触发；快速运镜结束立即恢复稳定；禁止持续无意义晃动/旋转/无动机运镜；不生成字幕/片中文字/标题/logo/水印/BGM。

### 四、场景空间锚点
| 槽位 | 字段 | 主源 |
|---|---|---|
| Scene ID | `scene_id` + `scene_sub` | S02 |
| 画面左/右/中央/前/后固定关系、其他固定锚点 | `spatial_anchors[]`（≥2） | S02 |
| 角色始终位置、主关系轴 | `screen_lock.characters[]`（screen_side: LEFT/RIGHT/CENTER，vertical: HIGH/LOW/EYE_LEVEL）、`screen_lock.main_axis` | S03 |
| 摄影机主要位于/主要朝向 | `spatial_anchors[]` 中 `kind: CAMERA_ANCHOR` 项 | S02（补丁③） |

固定约束渲染：除非剧情明确要求，不交换左右位置、不镜像反转、不无理由越轴。

### 五、承接上一段 15 秒
| 槽位 | 字段 | 主源 |
|---|---|---|
| 上段终帧全状态（人物位置/景深/姿态/朝向/视线/双手/伤势服装、道具、前中后景、场景视角、动作状态） | `start_state`（签名复制） | 上段 `final_state`；首段 = S02 首 BEAT `start_state`；跨集 = EpisodeHandoff |

固定约束渲染：本段 0.0 秒必须直接继承以上全部状态。

### 六、镜头时间轴（每镜一块）
| 槽位 | 字段 | 主源 |
|---|---|---|
| 镜头编号/起止秒 | `timeline[].shot_seq`、`start_s`/`end_s`（秒数累加，纯算术） | S03 秒数 |
| 焦段/光圈 | 由景别查映射表（§5） | `_shared` 映射表 + S03 景别 |
| 景别/机位 | `shot_map[].columns.景别/机位` | S03 |
| 画面空间（人物位置/景深层级/朝向、道具区域与持有） | `screen_lock` + 道具推导规则（道具归属 × 持有人位置；无持有人读 BEAT `props` 位置，补丁②） | S03 + S02 |
| 前/中/后景内容与焦态 | `shot_map[].columns.画面描述` 环境层 + BEAT `environment` | S03 + S02 |
| 场景视角锚点 | 同第四节 | S02 |
| 人物动作与表演（起点→核心动作→结果；眼神/面部/呼吸/重心/情绪） | `shot_map[].columns.画面描述`、`人物情绪/细节动作` | S03 |
| 摄影机运动/触发点/焦点起点落点 | `shot_map[].columns.运镜` + `导演备注`（触发与落点） | S03 |

固定约束渲染：动作必须体现真实物理重量、惯性、接触反馈和因果关系；一个镜头原则上只完成一个主要动作目标；快速运镜阶段允许短促方向性运动模糊，到达落点后立即恢复清晰。

### 七、时间轴内对白（写在对应镜头块内，禁止统一放文末）
三种块，按 `dialogue_policy` 选择：
- **有口型对白**：`[音色/年龄感/音质/语气/情绪/音量/语速/气息]` + 口型精确匹配台词（逐字原文）+ 关键词前停顿与主手势 + 关键词重音与主手势 + 台词后闭嘴表演留白。字段：`dialogue_delivery`（pause_before_keywords[]、stress_keywords[]、primary_gesture、after_hold_s）+ 原台词（SCRIPT 逐字）。
- **内心 OS**：同上音色行 + "内心OS，不需要口型匹配，人物嘴部保持自然闭合，只保留对应面部微表情" + 台词 + 关键词处声音变化与眼神动作。固定尾句："OS不生成字幕，不显示内心文字。"
- **无对白镜头**：固定文案"无对白，人物闭嘴，无随机口型。"

### 八、镜尾状态（每镜终帧）
| 槽位 | 字段 | 主源 |
|---|---|---|
| 人物最终位置/姿态/视线/手部、道具最终位置状态、摄影机最终机位、焦点最终落点 | `shot_map[].end_state` | S03（补丁①） |

固定约束渲染：下一镜必须直接继承该状态；不得在切镜后自动重置人物姿势、位置、道具或伤势。

### 九、后续镜头重复结构 →静态
固定文案：后续所有镜头重复同一结构，直到段时长结束。

### 十、全段光线与色彩
| 槽位 | 字段 | 主源 |
|---|---|---|
| 主光方向/色温 | `light_base.key_direction`、`light_base.color_temperature` | S02 |
| 人物亮面/暗面、轮廓光、背景亮度、道具高光 | `segment_light_color`（段级统一决策） | S05 |

固定约束渲染：必须保留人物眼神光、面部立体感和场景纵深；禁止全场大平光、暗部死黑、高光过曝、廉价蓝紫滤镜或无来源魔法光。

### 十一、全段摄影规格 →静态映射
24fps、180°快门固定；各镜焦段/光圈按 §5 映射表逐镜列出；固定约束：高速运动只在明确动作触发点发生；人物眼睛、嘴部、手指、关键道具和动作落点必须清晰。

### 十二、声音设计
| 槽位 | 字段 | 主源 |
|---|---|---|
| 固定环境声 | `sound_design.ambient[]`（由场景环境推导） | S02 |
| 镜头动作声 | `sound_design.action_sfx[]`（按镜头编号） | S03 画面描述 |

固定约束渲染：不生成 BGM；对白清晰优先，环境声/混响/特效声不得覆盖台词；所有声音必须符合画面空间方向（危险来自右后则声从右后）。

### 十三、全段连续性约束 →静态 + 段内锁
固定规则：人物脸部/年龄/肤色/发型/服装/伤势/身材全段稳定；左右关系与主空间轴一致（读 `screen_lock` 渲染具体锁）；场景固定物空间关系稳定（读 `spatial_anchors` 渲染）；道具形状/材质/尺寸/归属/状态连续；上一镜结果必须延续（门锁损伤持续、撕下裙摆不恢复、到手道具不消失、伤口不恢复）；动作严格遵循起点→过程→结果；禁止瞬移/站位跳变/无原因改姿势；未在剧本和素材中出现的人物/道具/建筑/剧情结果不得自行增加。

### 十四、负面约束 →静态词包
字幕/标题/logo/水印/片中文字/对白气泡/随机BGM；换脸/年龄漂移/肤色变化/发型漂移/服装变化/重复人物/随机群演增减；左右镜像/站位乱跳/无意义越轴/视线反转/动作方向反转；手指异常/多余肢体/穿模/人物与道具融合/道具穿身；场景结构变化/门窗互换/家具漂移/摄影机穿墙；无意义持续晃动/持续旋转/焦点漂移/快速运镜后仍模糊；擅自增加原剧本不存在的动作/道具/角色/场景/伤势/剧情结果。另镜像 `_shared/style-packs.md` 当项目风格负面词。

### 十五、本段最终承接状态
| 槽位 | 字段 | 主源 |
|---|---|---|
| 各人物画面位置/景深/姿态/朝向/视线/手部/伤势/情绪；各道具位置状态归属；前中后景内容与焦点；场景视角锚点；摄影机焦段/机位/运动状态/最终焦点；动作停点 | `final_state` | S05（段级生产，QA 检） |

固定约束渲染：这是下一段必须直接读取的状态；下一段第一帧必须直接从这一状态继续，不重新起动作。

## 3. 渲染模板

`render_segment_prompt.ps1` 按节序机械拼装：节标题行 → 静态文案/字段槽替换 → 镜头块循环（第六/七/八节按 `timeline[]` 逐镜渲染，第九节起恢复单块）。模板中的固定文案以 §2 各节"固定约束渲染"为唯一文本来源，渲染脚本不得改写措辞。

## 4. conformance 检查（S06 派生）

1. 节序完整且只出现一次；无额外节。
2. 每节内容与其 schema 字段一致；body 事实可指回字段。
3. 槽位集合与 `reference_bindings` 一致且连续自增。
4. 对白块位于对应镜头时间轴内，不在文末。
5. 时间轴：首镜 0.0 秒起，末镜于段时长止，镜间无重叠无空洞。
6. 第五节与上段 `final_state` 签名一致；第十五节字段齐备。

## 5. 景别 → 焦段/光圈映射表（唯一出处）

| 镜头类型 | 焦段范围 | 光圈范围 |
|---|---|---|
| 动作/空间镜头（大全景/全景） | 24–35mm | f/4–f/5.6 |
| 双人关系镜头（中全景/中景） | 35–50mm | f/2.8–f/4 |
| 人物近景（中近景/近景） | 50–70mm | f/2–f/2.8 |
| 脸部特写（特写/极特写） | 70–85mm | f/2–f/2.8 |
| 手部/道具特写 | 85–100mm | f/2–f/2.8 |

S03 写景别时不写焦段光圈；S05 渲染时查本表。其他文件只引用本表，不复制。
