# 专项返修短语库（唯一出处）

> RepairTicket 的 `must_fix` 专用措辞库，全集群唯一出处；其他文件只引用不复制。
> 每条短语 = 一个已定位的具体错误模式 + 标准修正指令。`must_fix` 必须落到具体镜号/格号，禁止"修好感觉"式写法。

## 1. 返修类型枚举

```yaml
repair_type: FULL_REDO | LOCAL_REPAIR | REINFORCE_CONSTRAINT
```

- `FULL_REDO`：整页/整段重做（S 级问题 >3 或版式错误时）。
- `LOCAL_REPAIR`：1–2 镜/格局部返修，其余内容并入 `preserve_scope` 锁定。
- `REINFORCE_CONSTRAINT`：内容方向正确但约束强度不足，加强约束重产。

## 2. 票据字段

```yaml
preserve_scope: <保留内容；并入 locked_fields 语义，返修时不得改动>
must_fix:      <必须修正项；逐条落到具体镜号/格号，使用 §3 短语或同精度措辞>
```

## 3. 专项短语

| 错误模式 | 标准修正指令 |
|---|---|
| 院内 ↔ 室内互错 | "镜 {n}：场景子类错误，院内（室外）画成室内（或反之）。按 S02 `scene_sub` 重产，保留人物站位与动作。" |
| 左右反转 | "镜 {n}：人物左右位置与 `screen_lock` 相反。恢复 {角色A} 在左、{角色B} 在右，不镜像其他元素。" |
| 标签遮脸 | "格 {n}：编号/标签遮挡人物面部。标签移至画面边缘留白区，不遮脸、不遮关键道具。" |
| 箭头全同向 | "页 {p}：运动箭头全部同向。按各镜实际运镜方向分别绘制，无运镜的格不画箭头。" |
| 红印 ≠ 流血 | "镜 {n}：伤势表现错误，红印画成流血（或反之）。按剧本伤势状态重绘，伤势程度与上游一致。" |
| 孕肚归属错误 | "镜 {n}：孕肚画到错误人物身上。孕肚仅属于 {角色}，其他人物腹部保持常态。" |
| 界碑锚点消失 | "镜 {n}：固定锚点 {锚点名} 消失或移位。按 `spatial_anchors` 恢复其画面方位与视觉特征。" |
| 越轴 | "镜 {n}：相对镜 {m} 无理由越轴。恢复主关系轴 {轴描述} 同侧拍摄，或按剧情要求显式标注越轴理由。" |
| 站位跳变 | "镜 {n}：人物位置与镜 {m} 镜尾状态不一致。按镜 {m} `end_state` 直接继承，不重置。" |
| 道具瞬移 | "镜 {n}：道具 {道具名} 归属/位置与上游状态矛盾。按 {来源字段} 恢复。" |

## 4. 使用规则

- 表内短语覆盖不了的新错误模式，先在本文件登记新短语再使用；禁止在票据里即兴发明模糊措辞。
- `must_fix` 每条必须含：定位（镜号/格号/页号）+ 错误模式 + 修正依据（字段名或上游产物）。
