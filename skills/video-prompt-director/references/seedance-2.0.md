## 1. 支持状态

当前项目具备 `Seedance 2.0 视频提示词执行规范 V3.4`，可将其登记为 `VERIFIED` 模型规则配置，例如：

```yaml
rule_id: SD20-V3.4
model: seedance-2.0
status: VERIFIED
supported_generation_tasks:
  - MULTIMODAL_REFERENCE
  - EDIT_VIDEO
  - EXTEND_FORWARD
  - EXTEND_BACKWARD
  - COMPOSITE
slot_syntax: "{{Mixed x}}"
body_char_limit: PROJECT_UNSPECIFIED
target_duration_seconds: 15
```

具体 `product_flow` 必须由当前产品配置提供并确认可用；本 reference 不猜产品界面名称。资料未给 Seedance 2.0 统一字符上限，不添加虚构限制。

## 2. 任务句式

- 多模态参考：声明当前人物、场景、道具和已批准分镜图的参考作用，再生成新视频。
- 编辑视频：正文直接写“严格编辑视频1……”，不要写“参考视频1”；未提及部分保持不变。
- 向后延长：只有模型实际收到视频1时写“向后延长视频1……”。
- 向前延长：只有模型实际收到视频1时写“向前延长视频1……”。
- 组合任务：区分“参考哪个素材”和“严格编辑哪个视频”，不要让两者的角色/槽位语义混合。

常规 APPROVED 分镜图生视频使用 `MULTIMODAL_REFERENCE`。

## 3. 素材槽位

开头格式：

```text
参考图素材说明：女主{{Mixed 1}}，父亲{{Mixed 2}}，客厅{{Mixed 3}}，确认分镜图{{Mixed 4}}。
```

规则：

1. 每条 Prompt 必须包含 `{{Mixed x}}`。有输入台账时绑定真实资产；没有时根据已确认剧情、分镜和连续性生成待上传资产计划。
2. 不使用 `@`、`{{Image x}}` 或旧平台槽位格式。
3. 人物、同类群体、场景、关键道具、能量体、怪物、神兽和确认分镜图按独立语义对象分别占槽。
4. 同一对象全篇只对应一个槽；不同对象不得共用同一槽。
5. 每条 Prompt 按当前实际需要去重，从 `{{Mixed 1}}` 开始连续自增，不留空号；结构化绑定与正文编号必须完全一致。
6. 后文首次出现重要对象时可再次带槽位，防止错绑。
7. 没有实际参考图的必要对象仍分配 `AUTO_PLANNED/REQUIRED_NOT_PROVIDED` 槽位；`asset_id`、版本保持空值，不伪造已存在资产。
8. 引用站位/分镜图时只继承已确认的人数、位置、距离、朝向、视线、道具、构图和空间连续性；不继承文字、水印、拼版编号、压缩画质或生成瑕疵。

引用图片后仍需自然语言重述 0 秒位置，不能只写“按图站位”。

## 4. 单段正文结构

一条正文只对应当前 `shot_id` 的一个连续可生成片段：

```text
参考图素材说明：……

参考已批准分镜图中的……；0秒时人物、场景和道具具体状态……本镜核心情绪……计划停在……

0-3秒：……
3-9秒：……
9-15秒：……

统一使用……焦段、f值、机位距离、焦点与可见景深；人物动作发生时的光影、色彩和材质……

现场对白/环境/动作/状态声……不要生成BGM……无字幕、文字、logo、水印……
```

Seedance 2.0 的目标总时长固定为 15 秒。时间轴必须从 0 开始、无重叠/间隙、最后准确等于 15 秒。不得输出其他总时长，也不得在同一正文出现“片段01/片段02”且各自从 0 秒开始。

## 5. 自包含空间

每个主要人物用五项锚定：横向位置、景深层、身体朝向、视线目标、邻近固定锚点。动态对象再写起点、路径和终点。

禁止只写“左前方、右后方、朝中央、看对面、道具在旁边”。每次目标机位变化都按世界锚点重新计算屏幕投影；不得复制上一镜左右。

双人关系先锁定两人的相对世界位置、当前投影、相向视线、两人之间的锚点及各自背后背景。过肩/正反打只有上游分镜已确认时才使用。

## 6. 动作、对白与声音

动作链使用：当前状态 → 触发 → 动作前兆 → 主动作 → 惯性/接触 → 停顿/恢复 → 反应。2–3 秒不塞多个完整动作。

对白格式转成自然正文，结构化字段保留：人物名、成年年龄层、音质、语气、情绪、音量、语速、气息和逐字台词。开口前有准备，结束后有停顿；一次一个主要说话人，其他人闭嘴并反应。

保留现场存在的环境声、状态声、动作声和对白声。结尾明确不要生成背景音乐 BGM，便于后期混音；这不代表静音。

## 7. 摄影和光影

每镜继承已确认景别、机位和主运镜；用单一焦段、单一 f 值、机位距离、焦点/跟焦路径和可见景深落实。每次运镜必须有动作触发和落点，不能堆推、拉、摇、移、环绕。

光线必须有场景来源和方向。把主光、负补、轮廓、实景光池、明暗分区和高光落点嵌入人物进入光区、抬眼、转头、开口、破防或动作接触的时刻；不要在末尾逐条宣称“已完成光影六层”。

## 8. 纯净度与禁止项

- 不把整集/整场总纲包装成“最终 Prompt”。
- 不输出多个重复 0 秒的片段。
- 不写 Emoji 标题、`END FREEZE`、`OS`、营销版本名或下一步建议。
- 不把内部规则、七格卡、白模、截图分析、QA 或镜尾卡放进正文。
- 不使用未决“或/任选/A-B”方案。
- 不用“统一空间锁定”“承接上一段”代替具体画面。
- 不用慢推填补静止表演，不用镜头抖动替代动作物理。
- 不写无动机光、泛化电影感、大平光或全场均匀明亮。
- 默认无字幕、文字、标题、logo、水印和 BGM；剧情必需文字必须来自精确上游文本。

Seedance 2.0 的最终正文仍需通过 `QA:VIDEO_PROMPT`，本 reference 不授予 PASS。
