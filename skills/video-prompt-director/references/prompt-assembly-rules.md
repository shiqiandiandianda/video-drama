## 1. 组装原则

最终正文不是剧情摘要或规则清单，而是一段正在发生的视频。每个时间段优先写：

```text
镜头起点
→ 动作触发
→ 唯一主动作与物理过程
→ 可见微表演和情绪变化
→ 已确认运镜的触发、路径与落点
→ 同时发生的声光反馈
```

正文中可见动作、表演、镜头变化和声音反馈应占主体；空间、技术和稳定性只保留生成所需内容。不要把内部七模块、光影六层或质检问题逐条外露。

一个规格只执行一个 `shot_id`。不得新增上游未确认的切镜。

## 2. 时长与负荷

Prompt 总时长由模型锁定：Seedance 2.0 只允许 15 秒，Seedance 2.5 只允许 30 秒。不得输出 6、8、10、20 秒等其他总时长，也不得把 15/30 写成“约”。时间轴必须完整覆盖对应总时长。

### 台词估算

只统计需要读出的汉字、数字和英文：

| 状态 | 建议语速 |
|---|---:|
| 克制、压抑、悲伤、威胁 | 2.5–3.2 字/秒 |
| 自然对白、正常说明 | 3.2–4 字/秒 |
| 焦急、争吵、快速吐槽 | 4–5 字/秒 |
| 老人、重伤、哭泣、喘息 | 2–3 字/秒 |

另留：开口前吸气/反应 0.3–0.8 秒；短停顿 0.2–0.4 秒；犹豫/哽咽 0.5–1.2 秒；结尾缓冲 0.5–1 秒；听者反应 0.5–1.5 秒。

不得为塞入时长而改写、删减或加速原始对白。

### 动作最低时间

| 动作 | 建议最低容量 |
|---|---:|
| 眼神转向、抬眼、抿唇 | 0.5–1.5 秒 |
| 转头、回身、后退半步 | 1–2 秒 |
| 静止起步 | 1–2 秒 |
| 走入画面并停下 | 2–4 秒 |
| 弯腰捡起道具 | 2–3 秒 |
| 捡枪、起身、稳定姿势 | 3–5 秒 |
| 拔出武器并瞄准 | 2–3 秒 |
| 单次点射/挥击 | 1–2 秒 |
| 投掷并击中 | 2–4 秒 |
| 能量形成、飞行、撞击 | 3–6 秒 |
| 飞入/救场/落地 | 3–5 秒 |
| 撞击后双方反应 | 1–3 秒 |

动作组合不能只取最大值；阶段之间通常还需 0.5–1 秒衔接。

### 负荷点预警

- 简单表演变化：1 点。
- 1–10 字台词：1 点；11–20 字台词：2 点。
- 新人物入画、复杂空间首次建立、关键道具抓取/交换/使用：各 2 点。
- 奔跑、投掷、开枪、扑倒：2 点。
- 飞行、打斗、能量攻击、救场、三人以上同时调度：3 点。
- 精确口型说话人切换：1 点。

建议预算：15 秒不超过 9 点；30 秒不超过 18 点。预算只做预警，不代替语义判断。

若负荷超出目标模型的 15/30 秒，S05 不自行删剧情。输出 `HUMAN_GATE`/返回 S03 重新分段，说明最小时间缺口和受影响动作/台词。内容不足时，只能展开剧情内已有的准备、惯性、反应、呼吸、环境反馈和稳定落点，不新增事件、重复动作或无动机慢推。

## 3. 动作物理

每个动作从以下七拍选择当前时长容纳的部分：感知、决定、起动、主动作、惯性、接触/落点、恢复。2–3 秒通常只能承载 2–3 拍。

优先写五项：

1. 触发：角色为什么此刻行动。
2. 主动作：这一时间段唯一主要动作。
3. 重量与惯性：支撑脚、重心、动力链和速度变化。
4. 接触与环境：手/脚/道具/地面/衣料如何响应。
5. 恢复落点：最终停在哪里，如何重新平衡或确认结果。

避免关节清单式写法。人物先有身体目标，再写与目标直接相关的 1 个主要反应和 1–2 个辅助反应。

关键道具必须先接触再承重再改变方向；换手需要时间。撞击同时影响施力者、被击者和环境。奔跑、挥击、投掷、射击或落地后不能瞬间完全静止。

切换时间段时继承速度、重心、持物手、道具位置、呼吸和摄影机惯性。

## 4. 真人表演

抽象情绪必须转成可见身体变化：视线、呼吸、肩线、重心、手指、喉结、嘴角、衣料和停顿。每镜只选与当前情绪相关的少量信号，不把所有五官同时写满。

高频场景：

- 主角登场：1–2 秒空间建立后，用门、手、脚步、衣摆或逆光制造局部悬念；给群像错时反应，再揭示正脸与关系位。当前分镜若未批准这些切换，不得在 S05 新增，需返回 S03。
- 羞辱对白：一个主攻击手势、关键词停顿/重音、已确认运镜落点、听话人或群像反应。
- 主角平静接招：先听见和判断，视线回收、肩线微松、重心不退、呼吸稳定，半拍后开口。
- 笑里藏刀：礼貌动作与台词后，笑意停半拍、喉结/眼神/袖中手指小变化，再恢复礼貌；不拍成阴森反派。
- 群像：只给 2–3 类不同步小动作；不全员同步，也不全员冻结。
- 2 秒以上近景：至少有两类与情绪相关的生命体征或微表演；没有变化时禁止用慢推填时长。

## 5. 对白与口型

每条对白记录：说话人、成年年龄层、音质、语气、情绪、音量、语速、气息、准确开始/结束时间和逐字来源。

规则：

1. 一次只有一个主要说话人准确开口。
2. 非说话人闭嘴，但用错时、低强度动作回应。
3. 开口前有吸气、视线或嘴唇准备；结束后有停顿和听者反应。
4. 台词文本逐字等于来源；只有来源已确认的标点/停顿变化才可采用。
5. 长台词不与抓取、翻滚、连续攻击等复杂动作同时进行。
6. 枪声、撞击、重喘会打断语流时，时间轴必须体现。
7. 画外音/旁白只有上游明确存在时才允许；不要把 `OS` 标签写入正文。

## 6. 运镜继承

运镜只来自 PASS 分镜行。S05 可以把抽象运镜转成执行细节，不能改换运动类型或增加切镜。

每个运镜写：起始景别和构图、动作触发、运动方式/速度、路径、终点对象/景别、停稳时间。一个镜头只有一个主要运动。

- 固定：对白、关系、道具和关键表演最稳。
- 推：只在情绪、危险或证据发生变化时使用；必须有触发和落点。
- 摇/移/跟：主体位移需要保持构图时使用，写清跟在哪一侧和最终锚点。
- 轻微手持：只继承已确认的危机/粗粝意图，不用抖动替代撞击物理。
- 环绕、FPV、变焦推拉：上游未明确时不得添加；空间高风险时进入 `HUMAN_GATE`。

## 7. 光影、色彩与材质

内部完成光影六层，但在正文中嵌入动作：

1. 主光来自什么、从何方向照向谁。
2. 哪一侧由墙、柱、夜色等负补压暗。
3. 发丝、肩线、武器或衣领如何被轮廓光分离。
4. 灯、窗、火、屏幕、路灯等如何形成局部光池。
5. 前中后景/楼层/门内外如何分区明暗。
6. 眼神、道具、能量体或服饰哪个局部是最高亮度。

色彩至少明确：环境基底、人物分离、强调色、危险色、黑位与中间调、最高亮度与高光滚降。禁止全屏青橙、廉价金黄、全场霓虹、肤色污染、塑料磨皮和纯白过曝。

近景写脸哪侧受光、哪侧保留阴影、眼神光来源和发丝/肩线分离。白衣主体保留灰白褶皱，只让银边、绣纹和局部肩线吃高光，脸部亮度优先。

材质只写当前可见且一致的皮肤、衣料、道具和环境反馈，不堆互相冲突的表面类型。

## 8. 声音

只选择画面中实际存在的声音：

- 对白声；
- 环境声，如风、雨、室内人群、洞穴回响；
- 状态声，如呼吸、吞咽、衣料、脚步；
- 动作声，如撞击、枪声、破风、道具接触。

默认 `NO_BGM` 不等于静音。声音尾部要与下一镜接口一致。不要列出整场可能出现但本镜没有发生的声音。

## 9. 正文顺序

正文固定为五个自然段区：

1. 参考素材/任务句式。
2. 批准站位来源、自包含 0 秒状态、核心情绪和计划停点。
3. 一套从 0 秒开始、总长准确的连续时间轴。
4. 统一摄影光学、光影、色彩和材质。
5. 现场声音、连续性和简短稳定性约束。

参考段示例格式：

```text
参考图素材说明：女主{{Mixed 1}}，父亲{{Mixed 2}}，客厅{{Mixed 3}}，确认分镜图{{Mixed 4}}。
```

无论调用方是否已上传资产，第一段都必须列出本镜需要的 Mixed 槽位。已提供资产写 `INPUT_LEDGER/PROVIDED`；未提供资产写 `AUTO_PLANNED/REQUIRED_NOT_PROVIDED`，从 `Mixed 1` 连续自增。自动槽位用于告诉调用方每个上传位置需要什么资产，不得附会不存在的资产 ID 或版本。

结尾约束保持精简：无字幕、文字、logo、水印和 BGM；人物身份、脸发、服装、比例、数量、槽位和关键道具稳定；动作自然，无卡顿、闪烁、穿模、变脸、换装或重复人物。

## 10. 硬拦截

- 多个镜头/片段共用一条正文，或正文多次从 0 秒开始。
- 正文总时长不是 Seedance 2.0 的 15 秒或 Seedance 2.5 的 30 秒。
- 只写剧情提纲，没有具体动作、表演、光影、声音。
- 新增分镜表未确认的切镜或运镜。
- 1–2 秒塞入转身、跪地、抓取、换握、瞄准和攻击。
- 台词丢字、改写、说话人错配或多人同时长句。
- 群像全员同步/冻结；2 秒以上近景人物完全静止。
- 运镜没有触发/落点，或同一镜叠加多种主运动。
- 光源无动机、大平光、全场等亮、白衣过曝。
- 缺少 Mixed 槽位、编号不从 1 连续自增、一槽多物、正文与 `reference_bindings` 不一致，或混入 `@`、`{{Image x}}`。
- 规则、QA、白模、截图、镜尾卡和营销话术污染正文。
- 用“承接上一段”“同上一镜”“按参考图”代替完整 0 秒状态。
- 可见人物缺少世界锚点、屏幕左/中/右、前/中/后景、朝向/视线或人物间横向/景深/距离关系，或只写“保持站位”“两人相对”等模糊描述。
- 任一时间段缺少 `spatial_execution`；人物不移动时也必须明确 `POSITIONS_UNCHANGED`。
- 未完成上一段镜尾→本段 0 秒及本段计划镜尾→下一段 0 秒的双向检查，或相邻 `handoff_signature` 不一致。
