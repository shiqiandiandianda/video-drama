## 1. 合格静态瞬间

上游分镜行：

| 景别 | 机位 | 运镜 | 画面描述 | 情绪/细节 |
|---|---|---|---|---|
| 中景 | 正面平视 | 固定 | 女主将通知书放到父亲面前。 | 女主克制期待；父亲注意力落向桌面。 |

合格：

```yaml
selected_moment:
  phase: FIRST_CONTACT
  source_evidence: "女主将通知书放到父亲面前。"
  frozen_state: "女主右手刚将通知书平放到父亲正前方，指腹尚未完全离开封面；父亲下巴微收，视线刚落到通知书。"
```

静态正文要点：女主画面左、父亲画面右；通知书在两人之间形成视觉锚点；女主重心仍在前脚，父亲尚未伸手。它没有画出“拿出、走近、放下、拿起、抬头”五个时间状态。

## 2. 多状态拦截

分镜行：

```text
女主从门口走到父亲面前，拿出通知书放下；父亲拿起看完后惊讶抬头。
```

处理：

```yaml
status: HUMAN_GATE
return_to: storyboard-table-director
reason: >-
  同一行包含走近、取物、放下、拿起、阅读、抬头六个连续状态，单张静态图无法忠实表达；
  需由 S03 确认拆镜或指定唯一关键帧。
```

S04 不得自行删掉父亲反应或擅自拆成两个 `shot_id`。

## 3. 夜巷连续镜组

对于“孤身女子在雨夜巷道遇袭”的 01–23 镜组，逐镜 Prompt 可以改变景别与投影，但必须共享以下世界事实：

- 同一条石子路、同一面高墙和同一列路灯；
- 女子湿发、深色厚外套与围巾状态连续；
- 手机在明确镜头前后保持同一所有者、位置和朝向；
- 袭击者出现前不能在早期镜头泄露完整身份；
- 路灯是最高亮度来源，雨湿地面只做局部反光；
- 黑白铅笔质感只有项目视觉母版明确锁定时才沿用。

镜 04 若分镜为“手握手机的局部特写”，只画手、外套口袋边缘与手机，不同时画女子走路和远处袭击者。镜 11 若为“袭击者从背后控制女子”，选首次控制成立的瞬间，写清双方重心、接触手和女子膝盖下沉，不画之后倒地。镜 18 的录音计时必须来自上游精确文本；没有源文本时不猜 `00:47`。

已生成单张图片通过 QA 后，才可以放入带红色镜号的 16 格/26 格审核板。空白拼版模板不是场景资产，也不绑定到单张 Prompt。

## 4. 文字镜头

若上游明确要求黑场时间卡“21:47”：

```yaml
frame_role: GRAPHIC_CARD
text_policy:
  mode: EXACT_SOURCE_TEXT
  exact_source_text: "21:47"
positive_prompt: >-
  单张竖屏9:16纯黑时间卡，画面中心仅出现精确白色字符“21:47”，
  字体简洁克制，字符水平居中、间距均匀；除该时间外无任何其他文字、图形、边框、logo或水印。
```

若上游没有精确时间，只写“出现时间卡”，必须请求源文本，不能自行填入时间。

## 5. RepairTicket 局部返修

工单：

```yaml
ticket_id: RT-E01-S01-003-002
qa_mode: STORYBOARD_PROMPT
artifact_id: SP-E01-S01-003
artifact_version: V1
full_id: SP-E01-S01-003-V1
verdict: REPAIR
issue_type: PROP_HAND_MISMATCH
evidence: 分镜表和连续性台账均锁定通知书由女主右手放下，Prompt 写成左手
repair_instruction: 将持物手和接触手恢复为女主右手
locked_fields:
  - 中景、正面平视
  - 女主画面左、父亲画面右
  - 通知书位置与朝向
  - 光线、服装、表情和场景结构
return_to: storyboard-image-prompt-director
max_attempts_remaining: 1
```

返修：

```yaml
artifact_id: SP-E01-S01-003
artifact_version: V2
full_id: SP-E01-S01-003-V2
prompt_id: SP-E01-S01-003-V2
source_version: V2
status: DRAFT
change_log:
  - field: selected_moment.frozen_state / positive_prompt / prop_states.contact
    old_value: 女主左手
    requested_change: 恢复为女主右手
    new_value: 女主右手
    unchanged: 景别、机位、站位、道具位置与朝向、光线、服装、表情、场景结构
```

禁止顺便改变构图、增强表情或更换焦段。

## 6. 常见失败

| 失败写法 | 原因 | 修正 |
|---|---|---|
| “三分法、低机位、电影感” | 没有可见位置 | 写清主体位于哪侧、空白留给谁、机位低到何处 |
| “女主走近、放下通知书，父亲拿起后抬头” | 多时态 | 选首次接触或结果刚成立的单一瞬间 |
| “同上一镜” | Prompt 不自包含 | 重述当前机位下的锚点、人物投影和道具状态 |
| “镜头慢推到她的脸” | 视频运镜污染静态图 | 选择推进路径上的明确摄影机位置和景别 |
| “人物很震惊” | 抽象表演 | 写呼吸停顿、下巴微收、视线锁定等可见信号 |
| “保持人物一致” | 资产约束不可执行 | 绑定真实人物资产 ID/版本并列出继承字段 |
| 直接生成 16 格并带镜号 | 模型容易串镜、错号、改构图 | 一镜一图，审核后再外部拼版 |
| 默认加入字幕、界面字 | 文字污染/编造剧情 | 默认禁字，只有精确源文本例外 |
