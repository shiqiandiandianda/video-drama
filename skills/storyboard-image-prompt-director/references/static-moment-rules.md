# 静态瞬间与电影语言转译

## 目录

1. 静态瞬间选择
2. 动作阶段
3. 情绪可视化
4. 景别与信息量
5. 机位、构图和光学
6. 光影与色彩
7. 拦截模式

## 1. 静态瞬间选择

分镜图不是动作连环画。先把分镜行拆成“初始状态 → 触发 → 过程 → 接触/结果 → 回稳”，只选择其中一个阶段。选择标准按优先级排列：

1. 忠实表达该镜的导演目的。
2. 在一帧内看清谁对谁做什么、关键道具在哪里。
3. 与上一镜结束状态和下一镜起点相容。
4. 人体重心和接触物理合理。
5. 构图仍符合上游锁定景别与机位。

默认用 `STORYBOARD_KEYFRAME`，选择信息量最高的动作峰值或首次结果成立瞬间。若上游明确要求视频首帧，则用 `VIDEO_START_CANDIDATE`，选择动作准备或触发前一刻，不得提前画出结果。

## 2. 动作阶段

可用枚举：

| 阶段 | 画面含义 | 适合场景 |
|---|---|---|
| `PREPARATION` | 意图已出现，动作尚未启动 | 对峙、准备起身、准备递物 |
| `PRE_CONTACT` | 身体已发力，尚未接触 | 伸手、挥击、即将撞上 |
| `FIRST_CONTACT` | 首次接触刚发生 | 手指触纸、手扶肩、脚落地 |
| `RESULT_ESTABLISHED` | 动作结果刚成立 | 道具落桌、人物倒床、门刚关上 |
| `RECOVERY` | 惯性正在回收，人物尚未完全静止 | 撞击后补步、落地后找平衡 |
| `REACTION_PEAK` | 事件后最清楚的可见反应 | 看清证据、突然察觉危险 |

动作物理要在一帧中成立：支撑脚承重、骨盆与胸廓方向一致，接触点明确，道具重量影响手腕/肩膀，被碰人物有合理反馈，衣料和发丝只呈现当前惯性方向。

禁止使用“先、再、随后、然后、逐渐、开始……最后……”串起多个状态。允许用“刚刚”“尚未完全”精确指示一个边界瞬间。

## 3. 情绪可视化

每镜只抓一个主要情绪，最多一个辅助情绪。把抽象词替换成 2–4 个互相一致的可见信号：

- 视线：落点、回避、锁定、短暂停顿；
- 呼吸：胸口起伏、鼻翼张力、嘴唇微启；
- 脸部：眉间、眼睑、下颌、嘴角、喉结；
- 身体：肩线、重心前后、是否后退、手指力度；
- 材质反馈：衣褶绷紧、湿发贴脸、袖口被攥住。

不要同时堆“震惊、害怕、愤怒、悲伤”。远景不写瞳孔和细小嘴角；近景不省略身体朝向和手部状态。

## 4. 景别与信息量

- 远景：环境规模、路径、孤立关系；不承担细表情。
- 全景：全身动作、人数、站位、进出路线。
- 中景：动作与表情兼顾，适合双人关系和道具交互。
- 近景：脸、肩线、呼吸、视线和手部成为重点；避免复杂全身动作。
- 特写：只突出单一脸部区域、手部或道具；前序必须已建立归属。

不得为增加电影感擅自把上游中景改成特写或把群像全景改为浅景深人像。

## 5. 机位、构图和光学

把术语转成可见位置：

- 三分法：写人物位于哪条三分线，视线空间留给谁。
- 中心/对称：写背景门框、道路或柱线如何向主体收束。
- 框中框/前景遮挡：写具体遮挡物、所占边缘和不能遮住的表演部位。
- 纵深：逐层写前景、中景、背景对象和危险方向。
- 压迫：写强者占据的面积、弱者被挤到的位置和压缩的头顶空间。
- 留白：写主体大小、位置和空白区域承载的威胁或孤独。

摄影机字段至少明确景别、实体高度、朝向、轴线侧和角度。光学参数必须服务上游景别：空间/群像通常 24–35mm、双人关系 40–50mm、单人近景 65–85mm、脸或道具特写 85–100mm。多人错层或关键道具与脸需同时清楚时避免极浅景深。

光学不是上游锁定项时可由 S04 选择单一可实现值，但必须在 `camera` 中标注为 `DERIVED_EXECUTION`；不得宣称来自分镜表。具体镜头系列的最大光圈未知时，不写品牌型号。

分镜表的推、拉、摇、移、跟拍只说明导演意图。静态 Prompt 选择该运镜路径上的一个明确摄影机位置，不写“镜头推进”“镜头跟随”或时间长度。

## 6. 光影与色彩

每张真人分镜图至少明确：

1. 主光来源和方向；
2. 脸或主体的暗侧负补；
3. 发丝/肩线/道具的轮廓分离；
4. 灯、窗、路灯、屏幕等实景光池；
5. 前中后景明暗分区；
6. 画面最高亮度落点。

色彩写环境基底、人物分离色、强调色/危险色、黑位与中间调、高光滚降。避免“电影级、低饱和、高级感”这类不可见空词。黑白铅笔或概念分镜风格只有项目视觉母版明确要求时才使用；默认真人写实电影截图。

## 7. 拦截模式

出现以下任一情况，不生成 Prompt：

- 同一人物在一张图中需要出现多个动作阶段或残影；
- 一个镜头行必须依赖多次切镜才能表达；
- 人物左右关系、轴线侧或关键道具持握手互相冲突；
- 分镜要求的人物/道具不在已通过剧情或资产中；
- 机位和景别无法同时容纳分镜要求的动作；
- 需要可读文字但源文本没有提供；
- 只能通过新增剧情动作才能让画面“合理”。

前五项通常返回 S03 或 `HUMAN_GATE`；资产缺失返回资产阶段；文字缺失要求提供精确源文本。
