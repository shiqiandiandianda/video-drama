## 1. 来源优先级

按以下顺序裁决：

```text
用户当前明确要求与最新确认
→ 项目锁定事实
→ PASS 分镜表与其导演备注
→ 人物/场景/道具资产及连续性台账
→ 项目视觉母版
→ 通用默认
```

同级来源冲突且没有确认结论时进入 `HUMAN_GATE`。不得用参考图中的偶然生成错误推翻锁定事实。

## 2. 绑定单位

每个独立语义对象使用独立绑定：

- 每个主要人物一个人物资产；群演只有确有群体资产时绑定群体资产。
- 场景资产与人物资产分开。
- 动作关键道具、怪物、能量体分别绑定，不与人物共槽。
- 同一资产必须记录 `asset_id` 与 `asset_version`。
- 同一对象在镜头组内保持同一个资产版本，除非上游明确换装、受伤或状态变化。

用户已经给出槽位编号时原样沿用，即使编号不连续；删除未出场素材也不得重新编号。没有真实编号时不生成假编号。

## 3. 继承与忽略

每个绑定必须写：

- `reference_role`：该图用于身份、外观、空间、道具还是构图。
- `inherit`：当前镜头必须继承的明确事实。
- `ignore`：不应传播的背景、姿势、文字、水印、画质或生成瑕疵。

人物定脸图通常继承脸、发型、体型和锁定服装，不继承其海报姿势、背景或光线。场景图继承结构、尺度、门窗、家具和材质，不继承错误人物。站位图只继承经确认的人数、世界位置、距离、朝向、视线、道具和构图层次。

## 4. 人物

逐人核对：

- 成年年龄层、身份、脸发、身形、服装层次、伤痕和污渍；
- 世界位置及邻近锚点；
- 目标机位下的屏幕左/中/右和前/中/后景；
- 双脚/骨盆朝向、胸口扭转、头部和视线；
- 支撑脚、重心、双手及与他人/道具的接触；
- 遮挡关系和可见范围。

同一人物在一张图中只出现一次。除非分镜明确要求镜面反射，否则禁止倒影造成第二张脸或重复人体。

## 5. 场景与空间投影

先锁世界空间，再计算屏幕投影：

1. 用门、窗、墙角、道路、路灯、桌边、楼梯、柱子等固定锚点还原世界位置。
2. 确认人物互动轴和摄影机合法侧。
3. 根据当前摄影机实体位置、朝向与高度，重算人物在画面中的左右和前后层级。
4. 将世界事实与屏幕投影分别写入规格。

换成反拍时，屏幕左右可能改变，世界位置不能改变。不得复制上一镜画面左右，也不得把斜俯视白模的画面左右当作目标镜头左右。

场景 Prompt 至少写清：前中后景、人物可站区、关键通道、A/B 机位背景、主要锚点、主光方向、暗部区和实景光池。

## 6. 道具

关键道具逐项写：

- 标准名与资产版本；
- 所有者；
- 持物手或接触身体部位；
- 当前世界位置和屏幕位置；
- 长轴/正面朝向；
- 打开、关闭、完整、破损、落地、平放等状态；
- 与上一镜相比允许发生的唯一变化。

不得为了“画面好看”换手、镜像、放大道具、添加第二件同类道具或给道具写未经来源确认的文字。

## 7. 文字和拼版

默认禁止字幕、说明、对话气泡、标题、镜号、坐标、图例、箭头、logo 和水印。

例外只来自分镜表：

- 手机/录音界面：只生成源分镜指定的必要字符，其他界面不编造。
- 招牌/文件：仅在剧情依赖可读文字时使用精确源文本。
- 黑场时间卡或字幕卡：设置 `frame_role: GRAPHIC_CARD` 与 `text_policy: EXACT_SOURCE_TEXT`，正文只描述该卡片，不混入真人画面。

镜号红圆标、白边框、16 格或 26 格排版属于审核拼版层。单张图生成后由外部工具添加，禁止进入 `positive_prompt`。

## 8. 缺失与冲突

以下缺失直接阻断：主要人物身份资产、场景核心结构、动作关键道具、目标画幅、世界位置/轴线无法从现有资料确定。

以下情况可以使用项目默认但必须记录：真实度、无文字策略、通用肤质和输出清晰度。

以下情况返回上游：

- 分镜行的人物位置和导演备注矛盾 → S03。
- 分镜要求一个不存在于剧情/资产台账的道具 → S03 或资产阶段。
- 连续性卡与已确认分镜冲突 → `HUMAN_GATE`。
- 参考图片本身左右镜像、错手或人物错误 → 不继承错误，要求重绑或返修图片。
