## 1. 动作链

每个需要被理解的动作按以下物理顺序组织：

```text
意图/注意转移
→ 支撑与重心准备
→ 发力或启动
→ 连续路径
→ 接触/受力反馈
→ 惯性与恢复
→ 结果状态
→ 自己或他人的即时反应
```

轻动作可以压缩，但不能只给结果。人物从站立变成倒地，必须让观众看到失衡、下坠/受力和落地反馈；递交道具必须交代哪只手、路径、接触、松手以及道具最终归属。

重量动作必须沿地面、腿、骨盆、躯干、肩臂传递。转身、抓物、投掷和急停要出现支撑、时间差、惯性与重新平衡。道具先接触、再承重、再改向；切镜不能让换握凭空完成。

## 2. 身体目标与拍数

先给人物一个身体目标，例如阻止、保护、施压、逃离或保持平衡，再选择与目标直接相关的动作。不要把眼睛、眉心、嘴唇、双手、膝盖逐项列成无因果的关节清单。

每镜通常只保留：

- 一个主要身体目标；
- 一个主要身体反应；
- 一至两个辅助反应。

动作拍从“感知 → 决定 → 起动 → 主动作 → 惯性 → 接触/落点 → 恢复”中选择。2—3 秒镜头通常只能清楚承载 2—3 拍，不能七拍全写完后再塞台词或第二个动作。

## 3. 拆镜判断

保持一镜的条件：

- 动作位于同一空间和同一关系轴；
- 只有一个主要视觉重点；
- 一个连续动作链能自然完成；
- 景别能同时承载必要动作与表情；
- 时长能容纳动作、对白和反应。

拆镜或延长的信号：

- 2—3 秒内塞入多个完整动作；
- 同时需要看空间、复杂身体动作和细微表情；
- 起身、奔跑、翻滚、取物、瞄准、开火等连续高负荷动作叠加；
- 三人以上调度、关键道具交换或突发登场；
- 两句以上完整对白与复杂动作并行；
- 一个镜头需要两个以上独立画面重点或多个主要运镜；
- 复杂动作、完整口型、大情绪转折和复杂运镜被安排在同一时刻；
- 动作结果、听话人反应或关键证据没有被读到。

不要为每个微动作单独切镜。眨眼、吸气、手指收紧、衣料回落等通常属于同一表演链，而不是独立剧情镜头。

## 4. 时长参考

| 内容 | 最低建议时长 |
|---|---:|
| 单个简单动作 | 1.5—2 秒 |
| 起身、走近、递交物品等完整动作 | 2—4 秒 |
| 一句短台词 | 2—3 秒 |
| 动作加一句台词 | 3—5 秒 |
| 多人连续反应 | 4—6 秒 |
| 特写反应 | 1—2.5 秒 |

常见动作的保守下限：

| 动作 | 建议时长 |
|---|---:|
| 转眼、抿唇等微动作 | 0.5—1.5 秒 |
| 转头、回身、退半步 | 1—2 秒 |
| 自然起步 | 1—2 秒 |
| 走入画面并停稳 | 2—4 秒 |
| 短冲刺 | 2—4 秒 |
| 弯腰捡起地面物 | 2—3 秒 |
| 捡枪、起身、抵肩并瞄准 | 3—5 秒 |
| 拔枪/刀并完成瞄准 | 2—3 秒 |
| 单次点射或挥击 | 1—2 秒 |
| 投掷并命中 | 2—4 秒 |
| 撞击后双方可读反应 | 1—3 秒 |

这些是明显不足的拦截线，不是统一镜长。额外预留：

- 空间建立通常 1—2 秒；
- 情绪或爽点前停顿通常 0.3—0.6 秒；
- 接触、惯性、落点和他人反应需要可读时间；
- 台词结束后给听话人或说话人半拍结果。

若为了塞进时长而删除动作前兆、接触反馈或结果，说明应拆镜或延长。

## 5. 对白与反应

时长是表演容量，不只是字数容量。先按语气估计中文对白时长，再叠加停顿、动作和听者反应：

| 语气/状态 | 参考语速 |
|---|---:|
| 克制、压抑、悲伤、威胁 | 2.5—3.2 字/秒 |
| 自然对话 | 3.2—4 字/秒 |
| 焦急、争吵 | 4—5 字/秒 |
| 老人、重伤、哭泣、喘息 | 2—3 字/秒 |

超过 5 字/秒容易含混或截断。使用：

```text
对白估时 = 有效字数 ÷ 对应语速
         + 开口前 0.3—0.8 秒
         + 逗号 0.2—0.4 秒/处
         + 省略或犹豫 0.5—1.2 秒/处
         + 说完缓冲 0.5—1 秒
         + 听者反应 0.5—1.5 秒
```

- 原台词逐字保留，维持说话人和发生位置。
- 开口前安排可见准备：吸气、视线落定、嘴唇先动、重心停住或手势起势。
- 关键词和重音绑定一个主手势或眼神变化，避免全程机械比划。
- 台词期间保留合适的身体动作，不让角色边复杂跑跳/打斗边说长句。
- 台词后写停顿或落点，并给听话人即时反应。
- 攻击性对白需要停顿、重音、手势、镜头落点和被攻击者反应，不能像朗读。

若对白自然时长已占镜头或片段 60% 以上，同时仍有复杂动作，必须拆分或延长，不得靠加速口型解决。

## 6. 真人微表演

把情绪词转成至少两类可观察变化，按剧情强度选择：

- 眼睛：视线停住、避开、追随、眨眼变慢、眼睑收紧；
- 呼吸与口部：吸气、呼气、屏息、喉结滑动、嘴唇轻颤、嘴角停住；
- 身体：肩线下沉/绷紧、重心前移/后撤、步幅变小、膝盖失去支撑；
- 手和接触：手指收紧/松开、拇指摩挲、抓握力度变化、触碰后回缩；
- 次级物理：衣料拉紧/回落、发丝受惯性或风影响、灰尘/水滴产生接触反馈；
- 时间：开口前半拍、看清后停顿、动作完成后的恢复。

2 秒以上近景/特写至少写两类。所谓“平静/克制”应表现为听见、判断、微停再行动，不是完全不动。

动作节奏不要匀速：准备稍慢，主动作加速，接触瞬间短促，恢复再次放慢。剧烈喘息、撞击或失衡会中断台词；先让人物恢复到能说话的呼吸和支撑状态。

## 7. 群像与登场

群像关系位只选择 2—3 类代表性小动作，错开节奏，例如停笑、转头、交换眼神、掩嘴、低语、后退半步。避免全员静止，也避免所有人同时转头或同步动作。

主角登场建议节奏：

```text
1—2 秒建立空间
→ 门、脚步、衣摆或影子等悬念局部
→ 群像注意力转移
→ 主角露脸
→ 关系位确认新权力结构
```

禁止在约 12 秒的登场里用 8—9 秒大全景等待人物走入。

这里的登场、羞辱对白和静态慢推改法来自“已出现失败模式”的纠偏经验；部分修正方案尚未完成视频复测。把它们用作风险警戒和默认启发，不要宣称为已验证成功模板，也不要覆盖项目已确认的导演决定。

## 8. 负荷预算与硬拆条件

用负荷点快速识别明显超载，不把分数当审美公式：

| 事件 | 负荷点 |
|---|---:|
| 简单表演或 1—10 字台词 | 1 |
| 11—20 字台词 | 2 |
| 新人物/复杂空间初建 | 2 |
| 关键道具交换 | 2 |
| 奔跑、投掷、开枪 | 2 |
| 飞行、打斗、能量、救场 | 3 |
| 三人调度 | 3 |
| 精确口型说话人切换 | 1 |

5/10/15 秒片段建议分别不超过 3/6/9 点；镜头数通常不超过 1—2/2—4/3—5。复杂动作、多人和长台词取下限。

出现以下任一情况，标记 `SPLIT_REQUIRED`：

- 三项大动作；
- 两次独立高潮；
- 攻击、第三人救场和后续对白挤在同段；
- 三人依次发言；
- 对白自然时长达到 60% 且仍有复杂动作；
- 依赖“立刻、同时、瞬间”才塞得下；
- 必须删除前兆、惯性或反应才放得下；
- 计划出现超过五次明显切镜。

## 9. 跨镜动作连续性

优先在发力、遮挡、接触或视线变化处切镜。下一镜必须显式继承：

- `velocity`：主体速度和移动方向；
- `center_of_gravity`：重心高度、偏移和支撑脚/支撑点；
- `held_prop`：道具所在手、握法、受力和归属；
- `breath`：喘息、屏息、说话能力和恢复程度；
- 接触后的惯性、衣发/液体/尘土反馈以及最终落点。

公开表不需要显示这些英文键，但“画面描述”和“导演备注”必须写出对应事实。不能只写“承接上一镜”。

## 10. 镜头容量自检

逐镜询问：

1. 观众能否指出唯一重点；
2. 初始状态、触发、过程和结果是否都可见；
3. 景别能否承载动作与表情；
4. 是否存在多个高负荷事件；
5. 台词能否以真人语速完成；
6. 是否给接触反馈、停顿和反应留时；
7. 近景是否有生命体征；
8. 群像是否有错开的小反应；
9. 运镜是否由动作触发并落在剧情信息上。

任一关键答案为否时，优先简化、延长或拆镜；不要通过堆术语掩盖容量问题。

## 短剧节奏规则

- 开场 hook：全剧或本集第一个镜头必须在 3 秒内给出冲突、悬念或强情绪画面；禁止以空镜、慢建立镜头开场，除非该空镜本身就是悬念载体。
- 反转密度：每 15 秒段内至多一个主要反转或信息揭示；单镜只完成一个主要动作目标，不把两个反转压进同一镜。
- 单镜信息容量：一镜只承载一个唯一画面重点（导演备注第一项）；台词、动作、反应三选二为高负荷上限，超荷优先拆镜。
- 时长纪律：单镜 ≥1.5 秒；段（15/30 秒）内 2–6 镜；同场镜头时间段连续无重叠无空洞。

## 窗口自检（连续 3 镜）

对每三个连续镜头组成的窗口逐项自检：

1. 不重复信息：同一信息（台词内容、动作结果、情绪揭示）不得在窗口内以不同措辞重复呈现；需要强调时改用景别或表演递进，而非重述。
2. 不无理由越轴：窗口内相邻镜的 `screen_lock` 左右关系与主关系轴保持一致；不一致者必须有 `director_note` 写明剧情理由。
3. 不重置状态：镜 n 的起始画面必须与镜 n-1 的 `end_state` 直接继承；人物姿势、位置、道具、伤势不得在切镜后自动重置。
4. 节奏不失控：窗口内景别无无理由的剧烈来回跳（如全景→极特写→全景），情绪强度曲线与剧情节拍一致。

任一检查失败，在交付前自行修正；窗口自检通过是提交 QA 的前置条件。
