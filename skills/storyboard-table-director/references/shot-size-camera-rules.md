# 景别、机位、运镜与空间连续性

## 目录

1. 决策顺序
2. 景别
3. 机位
4. 运镜
5. 轴线和世界锚点
6. 内部光学与风险判断

## 1. 决策顺序

先回答“观众此刻应感到什么、必须看懂什么”，再决定构图、景别、机位和运镜。每个技术选择都必须产生可见效果，不能只堆“低机位、慢推、低饱和、电影感”。

逐镜内部回答：

1. 唯一剧情节点和视觉重点是什么；
2. 主情绪是什么；
3. 需要看空间、身体动作、人物关系、脸部反应还是道具证据；
4. 观众应与角色平等、仰望、俯视、贴近、窥视还是代入；
5. 画面注意力是否真的需要移动；
6. 相邻镜头怎样继承位置、视线、道具和动作落点。

## 2. 景别

| 景别 | 主要承载 | 避免 |
|---|---|---|
| 远景 | 世界规模、环境压迫、孤独、灾难 | 眼神微表情、口型、细道具动作 |
| 全景 | 全身动作、站位、进出路径、群像关系 | 单独承担重大情绪爆点 |
| 中景 | 对白、取物、关系和身体动作兼顾 | 过多细微表情信息 |
| 近景 | 脸、肩线、呼吸、手部和情绪转折 | 复杂空间动作 |
| 特写 | 单一表情、手、证据或关键道具 | 未建立空间前孤立使用 |
| 极近特写 | 短促心理压力、怪异或夸张 | 长时使用、多人关系、真人变形风险 |

2 秒以上的近景或特写至少安排两类与情绪有关的生命体征或微动作。特写道具前先让观众知道它属于谁、位于何处。

## 3. 机位

| 机位 | 叙事功能 | 执行要求 |
|---|---|---|
| 平视 | 真实、平等、客观 | 优先用于多数对白和反应 |
| 低机位仰拍 | 力量、压迫、神圣、荒诞 | 写清低至腰、膝或贴地；严肃近脸镜克制畸变 |
| 高机位俯拍 | 弱小、孤立、被包围、空间关系 | 力量型情绪近景慎用 |
| 过肩 | 对峙、倾听、权力关系 | 写明从谁哪侧肩后拍谁；前景肩不挡主体眼嘴 |
| 背影 | 孤独、决意、面对未知 | 不承载需要口型的关键台词 |
| 主观 | 恐惧、寻找、苏醒、被追逐 | 短时使用并维持空间锚点 |
| 越肩压迫 | 强者占前景、弱者被压在后方 | 前景有轮廓但不遮死主体 |

“正面、侧面、背面、反拍”仍需与平视、俯仰、肩侧或实体锚点组合，做到可放置摄影机。

## 4. 运镜

每镜只使用一个主要运镜。优先固定；只有画面注意力或关系发生变化时才运动。

`手持跟拍` 可作为一个统一执行方式，`变焦推拉` 可作为一个明确命名的复合技法；`手持＋推`、`固定＋推` 或含糊的裸词 `推拉` 按多个主要运镜处理。若确指变焦推拉，必须写全名称及叙事目的。

| 运镜 | 使用条件 | 必写内容 |
|---|---|---|
| 固定 | 对白、站位、道具、反应、冷场、动作落点 | 主体在画面中的动作变化 |
| 推 | 情绪、危险、真相或决定逼近 | 起始景别、动作触发、速度、终点和落点 |
| 拉 | 揭示孤独、环境规模或反转后的疏离 | 从何主体拉到何种关系/空间 |
| 摇 | 从一个视觉锚点转到另一个 | 起点、路径、终点 |
| 移 | 横向展示关系或揭开遮挡 | 摄影机移动方向和新揭示对象 |
| 跟拍 | 陪同人物行动并保留连续性 | 跟在人物哪侧、保持哪个目标清楚 |
| 环绕 | 包围、仪式、眩晕 | 短时、明确弧度与落点；空间错乱高风险 |
| 升降 | 从渺小到宏大或从高位压下 | 起止高度和最终关系 |
| 手持 | 危机、粗粝、现场感 | 轻微真人起伏，不等于乱抖 |
| 甩镜 | 突发威胁或喜剧反打 | 短促并有清楚落点 |

慢推通常持续 2—5 秒，必须由抬眼、停步、破防、开口、发现信息等变化触发。无表演变化时禁止用慢推掩盖站桩。攻击性关键词可用 0.5—0.8 秒短促推进，之后接听话人或关系反应。

避免：

- 一个镜头同时推、摇、移、跟、环绕和升降；
- 普通对白、空间交代或道具展示机械推近；
- 以“稳定器＋手持＋跟拍＋推镜”堆设备和动作名词；
- 运镜没有触发、路径、落点或结束停顿。

## 5. 轴线和世界锚点

### 五项静态锚定

为每个主体写清：

1. 横向位置；
2. 前、中、后景；
3. 身体朝向；
4. 视线目标；
5. 附近不移动的视觉锚点。

动态对象再增加起点、路径和终点。画面左右是当前摄影机投影结果，不等于世界方向；换机位后必须由世界锚点重新投影屏幕左右。

### 双人关系

先锁定：A 在世界哪侧、朝向 B；B 在相对侧、朝向 A；二人之间的桌面或通道；二人各自身后的背景。选择一侧作为互动轴合法侧，正反打均留在该侧。越肩和近景继承视线方向，不因画面构图方便而交换人物世界位置。

### 多人和运动

- 先锁核心人物形成的主关系轴。
- 明确威胁或运动主体的世界方向、路径和最终落点。
- 让群像代表反应服务主关系，不建立相互冲突的新轴。
- 三人以上、复杂调度、正反打、环绕或出入门镜头标记站位图/白模确认。

导演备注至少记录：合法轴侧、人物左右和视线、进出方向、动态路径、关键道具在哪只手/何处、下一镜继承状态。

## 6. 内部光学与风险判断

S03 不新增焦段和光圈列，但内部可用以下范围检查可拍性：

- 18—24mm：空间建立，近脸畸变风险高；
- 28—35mm：动作和多人关系；
- 40—50mm：自然对白；
- 65—75mm：情绪近景；
- 85—100mm：表情或道具特写。

多人动作避免极浅景深。实质镜头内部应知道主光方向、人物明暗分区、实景光源和关键高光落点；只有它们构成连续性限制时才写入导演备注，完整光学和模型参数留给下游。
