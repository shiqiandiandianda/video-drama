# 门禁与失败路由样例

## 1. 上游未通过

输入：

```yaml
artifact_id: PLOT-E01
artifact_version: V2
full_id: PLOT-E01-V2
status: REPAIR
issues:
  - 第 3 个 BEAT 的原始对白说话人待核对
```

正确响应：

```yaml
artifact_type: GateBlock
stage: S03
verdict: BLOCKED_BY_INPUT_GATE
evidence: PlotProgressionSpec.status 为 REPAIR，不是 PASS
required_action: 完成 PLOT QA 并提供 status: PASS 的新版本
return_to: script-plot-progression
```

不要生成“临时分镜”、猜测说话人或把问题带入下游。

## 2. 未确认导演想法冲突

已通过剧情写“女主把通知书放在桌面”，未确认的讨论稿写“女主撕掉通知书”。两者改变剧情结果，S03 不得自行选更戏剧化的方案。

正确路由：`HUMAN_GATE`，列出两个来源、冲突字段和需要导演确认的唯一问题。

## 3. 动作超载

失败行：

| 场景 | 镜号 | 景别 | 机位 | 运镜 | 画面描述 | 秒数/s | 人物情绪/细节动作 | 导演备注 |
|---|---:|---|---|---|---|---:|---|---|
| 夜外／巷道 | 01 | 近景 | 正面平视 | 推＋摇＋跟拍 | 女主转头、起身、捡起手机、跑向巷口并接听电话，说完一整句求救台词。 | 2 | 女主非常害怕。 | 电影感，紧张。 |

问题：近景无法承载完整空间动作；2 秒超载；三种主要运镜；缺动作过程和结果；情绪抽象；没有轴线、路径、声音或连续性。应拆成空间/起身取物、移动、接听与反应等必要镜头，或重构时长，但不得改原台词。

## 4. 无理由碎镜

若“抬手—手指碰纸—纸张下落—纸角落桌—手松开”被拆成五个近似特写，而剧情只需要看懂一次递交通知书，应合并为一个完整动作镜头。只有证据揭示、主观认知变化或关系反应需要独立视觉重点时才切镜。

## 5. 越轴与左右漂移

前镜锁定女主世界左、父亲世界右，二人隔桌对视；后镜仅为构图方便写成女主世界右、父亲世界左，却未通过中性镜头或摄影机过轴动作建立新空间。这是镜头设计错误，返回 S03；不要用“反拍所以左右交换”辩解世界站位变化。

## 6. 下游错误不改表

若分镜表明确写“通知书在父亲面前”，但生成图片把它放到女主手里，而分镜 Prompt 本身转译正确，问题属于图像生成/图像 QA。不得反向修改正确的 S03 表去迎合错误图片。

## 7. 只有分镜拼板图片

只有带镜号的分镜拼板或空白格模板，不等于 S03 的合格上游。若图片缺少 `PlotProgressionSpec.status: PASS`、BEAT 映射、场次/人物资产、时长、台词、运镜和连续性字段，应把它归为视觉参考或 S04 下游样例，并返回输入门禁缺失清单；不得仅凭静帧猜动作、说话人和镜头时长后恢复一份“正式分镜表”。

图片可帮助识别景别递进、信息揭示和可能的动作连续性，但不能证明固定版式、真实时间容量或剧情事实。多个黑场、时间卡或字幕格也必须有上游剧情依据，不能因样例存在就自动加入新项目。
