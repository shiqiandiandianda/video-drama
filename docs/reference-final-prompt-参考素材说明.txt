十三、全段连续性约束

只保留真正重要的连续性规则，不重复镜头内容。

人物脸部、年龄、肤色、发型、服装、伤势和身体比例全段稳定。
人物左右关系和主空间轴保持一致，除非剧情明确要求，不交换位置、不镜像反转、不无理由越轴。
场景固定建筑、门窗、家具、楼梯、地毯、树木、道路等空间关系稳定。
道具形状、材质、尺寸、归属和状态连续。
上一镜产生的结果必须延续到下一镜，例如：
门锁损伤持续存在；
撕下的裙摆不会自动恢复；
已经拿到手中的道具不能突然消失；
已经出现的伤口不能恢复。
人物动作严格遵循：
动作起点 → 动作过程 → 动作结果。
不允许人物瞬移、站位跳变、道具瞬移、角色突然恢复体力或无原因改变姿势。
未在剧本和素材中出现的人物、道具、建筑和剧情结果不得自行增加。
十四、负面约束

禁止：

字幕、标题、logo、水印、片中文字、对白气泡、随机BGM。

禁止人物换脸、年龄漂移、肤色变化、发型漂移、服装变化、重复人物、随机群演增减。

禁止左右镜像、站位乱跳、无意义越轴、视线反转、动作方向反转。

禁止手指异常、多余肢体、身体穿模、人物与道具融合、道具穿过身体。

禁止场景结构变化、门窗互换、家具漂移、摄影机穿墙或进入不存在的空间。

禁止无意义持续晃动、持续旋转、焦点漂移、快速运镜结束后人物仍然模糊。

禁止擅自增加原剧本不存在的关键动作、道具、角色、场景、伤势或剧情结果。

核心生成原则

最终提示词必须遵守以下优先级：

第一优先级：剧情因果正确。

第二优先级：人物位置、前中后景和场景空间正确。

第三优先级：人物动作与上一镜连续。

第四优先级：人物表演和对白节奏正确。

第五优先级：运镜与构图正确。

第六优先级：摄影参数与视觉质感。

摄影参数不能凌驾于剧情和人物动作之上。

最终原则

提示词不是越长越专业。

每一条信息必须至少解决以下一个问题：

谁在哪里
谁是实焦
谁是虚焦
摄影机在哪里
摄影机朝哪里
人物正在做什么
为什么这样动作
摄影机什么时候移动
焦点落在哪里
人物什么时候说话
台词怎么说
关键词配什么动作
镜头结束在哪里
下一镜如何承接
下一段15秒如何继续

如果一段文字不能解决以上任何问题，并且只是重复解释、文学描述或重复限制，应当删除。

Skill后台可以复杂，但最终视频提示词必须清楚、直接、高信息密度。
